# M6.7 – Persistent Orchestration Service & Lifecycle

## Scope
M6.7 adds the application service layer for persistent orchestration management. It sits above `OrchestrationRepository` and owns orchestration lifecycle rules without introducing dependencies on Assessment, Rules, Knowledge, Publishing, or Workflow execution.

## Components
- `PersistentOrchestrationService`
- `OrchestrationNotFoundException`
- `OrchestrationLifecycleException`

## Lifecycle
- `DRAFT -> RUNNING`
- `RUNNING -> COMPLETED`
- `RUNNING -> FAILED`
- `COMPLETED` and `FAILED` are terminal.

Metadata can only be changed while an orchestration is `DRAFT`.

## API
- create
- get
- findAll
- findByType
- findByStatus
- updateMetadata
- start
- complete
- fail

## Boundary
The service depends only on the `OrchestrationRepository` SPI. Persistence implementation details remain outside the service.

## Non-goals
- cross-domain execution
- step execution
- Assessment/Rules/Knowledge/Publishing integration
- workflow integration
- API/web exposure

## Definition of Done
- service compiles on Java 21
- lifecycle transitions are tested
- invalid and terminal transitions are rejected
- metadata mutation rules are tested
- not-found behavior is tested
- query delegation is tested
- full Maven reactor remains green
