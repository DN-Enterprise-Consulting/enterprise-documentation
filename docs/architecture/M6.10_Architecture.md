# M6.10 – Orchestration Runtime Composition

## Purpose

M6.10 introduces the runtime composition boundary for the orchestration module.

## Composition

`FileOrchestrationPersistence`
→ `FileOrchestrationRepository`
→ `PersistentOrchestrationService`
→ `OrchestrationRuntime`

Callers obtain the persistent orchestration service through `OrchestrationRuntime.fileBacked(Path)` and do not need to construct infrastructure adapters themselves.

## API

- `OrchestrationRuntime.fileBacked(Path)`
- `OrchestrationRuntime.orchestrationService()`

## Guarantees

- file-backed persistence is used by the runtime factory
- orchestration state survives runtime recreation
- null storage directories are rejected explicitly
- no framework dependency is introduced
- cross-domain execution is intentionally not part of M6.10

## Boundary

M6.10 composes existing M6 persistence, repository, service, query and validation capabilities. It does not yet execute Assessment → Rules → Knowledge → Publishing. That cross-domain execution is a later milestone.
