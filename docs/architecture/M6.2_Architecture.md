# M6.2 – Orchestration Repository Contract

Defines the persistence-agnostic `OrchestrationRepository` SPI.

Methods:
- save
- findById
- findAll
- findByType
- findByStatus
- existsById

No persistence technology, framework, service, runtime, or cross-domain execution is introduced.
The SPI depends only on the orchestration domain and is verified by a contract test double.

`save` must return the object passed to it.
