# M6.1 – Cross-Domain Orchestration Domain Foundation

## Goal
Introduce an explicit orchestration domain for coordinating the existing platform domains.
This milestone defines the domain model only; it does not execute cross-domain work.

## Target process
Assessment -> Rule Evaluation -> Knowledge Processing -> Publication

## Domain model
- OrchestrationId
- OrchestrationType
- OrchestrationStatus
- OrchestrationStepType
- OrchestrationStepStatus
- OrchestrationStep
- OrchestrationMetadata
- Orchestration

## Boundary rules
1. No dependency on Assessment, Rules, Knowledge, Publishing, or Workflow in M6.1.
2. No framework or persistence technology.
3. No execution adapters.
4. Step ordering is explicit and contiguous.
5. Domain objects are immutable.
6. Existing modules are not changed except for root module registration.

## Non-goals
Persistence, repository, orchestration service, adapters, actual assessment/rule/knowledge/publication
execution, runtime integration, and API integration are later M6 milestones.
