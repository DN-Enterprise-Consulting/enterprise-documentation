# M6.9 – Orchestration Validation & Hardening

## Scope

M6.9 introduces explicit validation and hardening for the orchestration service and query paths without introducing cross-domain execution.

## Components

- `OrchestrationValidator`
- `OrchestrationValidationException`
- validation integrated into `PersistentOrchestrationService`
- validation integrated into `OrchestrationQueryService`

## Validation

- orchestration identity, type and status
- metadata name, description and attributes
- metadata attribute keys and values
- non-empty orchestration steps
- contiguous step sequence numbers
- step type and status

## Hardening

- null dependencies rejected
- created, loaded, updated and transitioned orchestrations are validated
- query results are validated before exposure
- terminal lifecycle semantics from M6.7 remain unchanged
- no dependency on Assessment, Rules, Knowledge, Publishing or Workflow

## Definition of Done

- validation unit tests green
- service validation tests green
- query validation tests green
- full Maven reactor `mvn -B clean verify` returns `BUILD SUCCESS`
